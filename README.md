# 한국 온라인 포커 토너먼트 시간표

WPL과 한게임 로얄홀덤의 하루 토너먼트 일정을 현금 기준 바이인으로 비교해 보는 페이지입니다.

- 지금 시각(한국 시간) 기준으로 늦은 등록 중인 대회와 다음 대회를 보여줍니다.
- 바이인 구간, 사이트, 형식(터보·바운티), 이름으로 거를 수 있습니다.
- 금액 단위를 현금(원) / WPL 코인 / 한게임 코인 중에서 바꿔 볼 수 있습니다.

## 기준
- 환율: WPL·피망 1억 코인 = 1만 원, 한게임 50억 코인 = 1만 원
- 늦은 등록 마감
  - 한게임: 시작 + 블라인드(분) × 레벨 + 지나가는 휴식(매시 55~00분) 5분씩
  - WPL: 시작 + 게임 안내 늦은 등록 시간(분). 예: 클래식 70억 08:30 시작 → 77분 → 09:47 마감 (2026-10-04 게임 화면으로 확인)
- 한게임 목록은 2026-10-04(일) 기준이며 이후 변경될 수 있음. HPT 새틀라이트 제외. 평일 운영 여부는 아직 확인 전.

## 참고
- WPL 늦은 등록 시간은 [0Shadow0-kr/WPL-tournament-alarm](https://github.com/0Shadow0-kr/WPL-tournament-alarm)의 값과 대조했습니다 (워밍업 20억 GTD 블라인드만 6분/5분으로 다름, 미확인).
