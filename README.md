# 한국 온라인 포커 토너먼트 시간표

WPL과 한게임 로얄홀덤의 하루 토너먼트 일정을 현금 기준 바이인으로 비교해 보는 페이지입니다.

- 지금 시각(한국 시간) 기준으로 늦은 등록 중인 대회와 다음 대회를 보여줍니다.
- 바이인 구간(직접 입력 포함), 사이트, 형식(터보·바운티), 이름으로 거를 수 있습니다.
- 금액 단위를 현금(원) / WPL 코인 / 한게임 코인 중에서 바꿔 볼 수 있습니다.
- 시간 옆 ★로 즐겨찾기를 하고 "즐겨찾기만"으로 모아 볼 수 있습니다. 즐겨찾기는 각자 브라우저에 저장됩니다.
- 알림을 켜면 즐겨찾기한 대회의 시작 N분 전, 늦은 등록 마감 N분 전에 알려줍니다 (페이지를 열어 둔 동안만, PC 권장).
- 오른쪽 위 버튼으로 시스템 / 라이트 / 다크 화면을 고를 수 있습니다.

## 기준
- 환율: WPL 1억 코인 = 1만 원, 한게임 50억 코인 = 1만 원
- 늦은 등록 마감
  - 한게임: 시작 + 블라인드(분) × 레벨 + 지나가는 휴식(매시 55~00분) 5분씩
  - WPL: 시작 + 게임 안내 늦은 등록 시간(분). 예: 클래식 70억 08:30 시작 → 77분 → 09:47 마감 (2026-10-04 게임 화면으로 확인)
- 한게임 목록은 2026-10-04(일) 기준이며 이후 변경될 수 있음. HPT 새틀라이트 제외.
